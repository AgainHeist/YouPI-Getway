Privacy & Copyright

Short version: your uploads are yours, they are temporary, and we do not stream movies for you.

What we store

  • The file you upload and its derived files live only inside that project's folder.
  • Project metadata in a local SQLite database.
  • No analytics, no third-party trackers, no advertising SDKs.
  • If you configure an external translation API, dialogue text leaves your server.

Deletion and retention

  • Delete any project instantly from History.
  • Everything is deleted automatically after the retention period.
  • Uploads are never listed publicly.

Copyright

  • Only process content you own or may legally process.
  • BhashaFlix is a personal dubbing tool, not a streaming service.
  • Voices do not impersonate real performers by default.
  • Model licences matter: XTTS-v2 (CPML), Colab terms, pyannote model terms.

Security

  • Uploads are validated by extension, magic bytes, probe, duration and audio tracks.
  • API keys stay on the server.
  • Set BFLIX_API_TOKEN to require a token for all API calls.
